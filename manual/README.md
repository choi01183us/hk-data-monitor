# manual/ — 人手維護嘅數據

> 呢份係**人手維護清單**。半年後要更新數據,睇返呢份就夠,唔使睇 code。
> 規則(SPEC 第 6 節):**唔好寫 PDF parser,一律人手抄一次。** 自動化 PDF 解析嘅維護成本會爆。
> 規則(SPEC 第 7 節):GitHub Actions **永遠唔碰** 呢個目錄。呢度嘅檔只有你會改。

## 點運作

1. 每個檔係一個指標,格式同自動抓嘅完全一樣(SPEC 第 5 節 schema),只係 `"acquisition": "manual"`。
2. `src/data/<id>.json.js` 會讀呢度嘅 JSON,驗 schema,再同自動抓嘅一視同仁咁出到網站。
3. **數值填 `null` 就係「未填」**。全部 `null` 嘅指標:網站會 build 到,但首頁唔會出佢張卡,頁面會顯示「數據未填」。
   咁做係跟 SPEC 第 2 節第 4 條:「唔准估數……寧願個指標唔出現。」
4. 填完之後跑 `npm run build`，已在頁面登記的資料卡會更新；香港指標在香港首頁，澳門四項在澳門專頁。`npm run validate` 會幫你驗 schema。
5. `_` 開頭嘅欄位(例如 `_maintainer_notes`)係畀你自己寫筆記用,唔會出到網站。

## 每個檔要抄乜、去邊度抄、幾時抄

### `phr_waiting_time.json` — 公屋輪候時間

| | |
|---|---|
| 去邊度抄 | https://www.hb.gov.hk/tc/publications/housing/cwt/index.html(**房屋局**,唔係房委會 —— 房委會嗰版而家只係轉介)|
| 幾時更新 | **每季**。房屋局每季公布一次,通常喺季尾之後一個月內 |
| 抄邊幾個數 | 一般申請者嘅「綜合輪候時間」(CWT,含簡約公屋)、一般申請者嘅「平均輪候時間」(AWT,只計傳統公屋)、長者一人申請者嘅平均輪候時間 |
| 期數點寫 | 網頁寫「截至 YYYY 年 M 月底」→ `period` 用季度寫法,例如 6 月底 = `"2026-Q2"`,9 月底 = `"2026-Q3"` |
| 單位 | 年(可以有一位小數,例如 `4.8`)|

**⚠️ 兩個數字定義唔同,唔可以撈亂:**
- **CWT(綜合輪候時間)** 計埋簡約公屋,數字細啲
- **AWT(平均輪候時間)** 只計傳統公屋,數字大啲

兩個都要抄,`category` 要寫清楚係邊個。畫面會兩條線並列顯示,由學生自己睇分別。

> 探路嗰陣(2026-09-04)喺網頁讀到:截至 2026 年 6 月底,CWT 4.8 年、AWT 5.5 年。
> **呢兩個數係 AI 探路員讀返嚟嘅,未經你核對,所以 JSON 入面照樣留 null。** 你開返嗰版對一對再填。

**歷史數列**:live 頁面只有最新一季。想要成條線就要開房屋局嘅季度 PDF 逐季抄,
一年抄 4 個數,成本可以接受。抄一季加一個 `period`。

**授權**:hb.gov.hk **冇**開放數據授權頁,係全站 13 個來源入面授權最弱嗰個。
JSON 入面 `licence` 暫時寫「房屋局網頁,一般政府網站版權告示」。畫面會照樣顯示來源連結。

### `public_expenditure_policy_groups.json` — 公共經常開支(十個政策組別)

| | |
|---|---|
| 去邊度抄 | 財政預算案「附錄 B」PDF：`https://www.budget.gov.hk/{YYYY}/chi/pdf/c_appendices_b.pdf`，例如 [2026 年附錄 B](https://www.budget.gov.hk/2026/chi/pdf/c_appendices_b.pdf) |
| 幾時更新 | **每年一次**，2 月尾預算案發表之後 |
| 經常開支 | 第 II 部：**公共 PDF p8／印刷 p22**；政府口徑喺 PDF p9／印刷 p23，唔好抄錯頁 |
| 開支總額註腳 | 第 III 部：**公共 PDF p11／印刷 p25**；政府口徑喺 PDF p12／印刷 p26 |
| 政策分類對照 | 第 VII 部 **PDF p18／印刷 p32**：「政策組別分類」，有十個政策組別與政策範圍對照。編號去到 34 但冇 33，唔好當成 34 個範圍。暫只留喺維護指引，未放上學生頁面 |
| 同一次抄邊三年 | 同一頁印住 **2024-25 實際、2025-26 修訂預算、2026-27 預算**，三年一齊抄。右方名義／實質變動百分比係另一種數，唔係開支金額 |
| 單位 | PDF 寫「百萬元」。**JSON 照抄百萬元嘅數字**(例如 `102308`)，唔好自己乘，loader 會乘一百萬換算成港元 |

**口徑已拍板用公共經常開支。** 按附錄 B 第 I 部 PDF p4／印刷 p18：

**公共開支 = 政府開支 + 營運基金 + 房屋委員會**

房委會同營運基金係分開兩項。2026-27 房屋公共經常開支為 22,635 百萬元，政府口徑只有 1,226 百萬元。
用政府口徑描述公共房屋資源會漏咗房委會，直接影響學生分餅同寫《青年預算備忘》。
自動抓嘅 `govt_expenditure` 繼續用政府口徑：**兩指標唔可以放同一張圖，亦唔可以將兩者總額相加**。

**三條檢查會喺 `npm run validate`／build 前跑，唔使上網：**

1. `category_order` 同每個年度 `series` 嘅 `category` 必須完全跟 PDF 次序，連 null 骨架都驗：
   教育 · 社會福利 · 衞生 · 保安 · 基礎建設 · 環境及食物 · 經濟 · 房屋 · 社區及對外事務 · 輔助服務。
2. 已填嘅教育／社會福利／衞生逐項對相同年度 `src/data/_snapshots/govt_expenditure.json` 嘅 FSTB CSV 數值。
   三組喺公共同政府口徑完全相同；loader 會先統一百萬元／港元單位。缺少對應年度或數字不符會 hard fail，唔會估數或退返舊快照。
3. 每年填齊十組後，相加必須對得上 `expected_totals`：2024-25 **583,548**、2025-26 **596,948**、2026-27 **625,033** 百萬元。
   門檻固定為原始單位 **1 百萬元絕對差**；唔准調鬆或者改成百分比。填齊一年但冇填該年總額亦會 fail。

次序檢查防止按錯行填；跨來源錨定防教育／福利／衞生嘅值對調；總額檢查夾住餘下七組嘅和。
**餘下七組之間單純交換數值仍可能通過**，所以逐行對 PDF 仍然不可省略。
如果下一年 FSTB 修訂咗舊年度數字而舊 PDF 未跟，核對同年度新版 PDF 後一併更新，唔好略過錨定或改門檻。

**每年抄數清單：**

- 第 II 部同頁三年，各抄十個組別值及 PDF 印住嘅經常開支總額。
- 第 III 部同抄三年**公共開支總額**，更新 JSON `notes_zh` 內嘅註腳：2024-25 實際 **801,223**、2025-26 修訂預算 **844,217**、2026-27 預算 **904,724** 百萬元。
- 註腳要清楚講：**625,033 係 2026-27 公共經常開支，唔係全年公共開支總額**。分餅用經常開支作「每年點分」嘅基礎，因為基本工程逐年上落較大。
- 更新 `source_url`、`source_note_zh`、`licence_url`、`updated_at`(文件數據截至日)、`transcribed_at`(抄數日)、`period_notes`、`expected_totals` 同 `notes_zh` 嘅年度及金額。
- 三年骨架嘅 `series.value` 暫留 null，等擁有人逐行抄入。上面總額已由 2026 年官方 PDF 核實；唔好將骨架當成已填。
- 填齊之後，頁面可選每年金額或相鄰年度名義增減，預設最近兩年；正數增加、負數減少。未填齊嘅年度唔會拿來計增減。

**授權**：[budget.gov.hk 版權告示](https://www.budget.gov.hk/2026/chi/important.html)只准個人參考或教育用途，複製本不能轉售。本專案係教育用途。

### `banking_institutions.json` — 銀行及接受存款機構數目

| | |
|---|---|
| 原始來源 | 金管局《金融數據月報》表 3.1 [T0301.xls](https://www.hkma.gov.hk/media/eng/doc/market-data-and-statistics/monthly-statistical-bulletin/T0301.xls)，工作表 `T3.1` |
| 本次範圍 | **2026 年 8 月底一個月份**。2026-09-09 實讀原表逐格核對；API 三次有限時查詢均回 502，因此明示為人手資料，唔假裝自動更新，亦唔寫 XLS parser 或加程式依賴 |
| 幾時更新 | 原表每月更新；課堂使用前核對最新一期並人手抄入。GitHub Actions 不會更新本檔 |
| 抄哪六欄 | 持牌銀行、有限制牌照銀行、接受存款公司，各有本地／境外註冊兩欄，按原表次序逐欄填 `source_components[period]` |
| 原始總數 | 另抄原表 **所有認可機構** 至底稿 `all_ais` 及 `totals`。`lros` 是本港代表辦事處，只留底稿辨別欄位，**不加入 series 或 totals** |
| 單位及日期 | 單位為 **間**，倍率固定 `1`。`period` 用 `YYYY-MM`，`updated_at` 用最新一期真正月末，例如 `2026-08-31`；`transcribed_at` 才填抄數日 |

本次原表定位：Excel 第 **447** 行為 2026 年 8 月（年份見第 440 行）。D/E 欄 32／115、
F/G 欄 9／7、I/K 欄 11／0、M 欄所有認可機構 174、O 欄代表辦事處 27。
三類輸出依次為 **147、16、11**；**147 + 16 + 11 = 174**。下次更新行號會變，先核對年份、月份和表頭，唔好只靠格地址。
`source_components` 留下原始八格底稿作逐欄核對；loader 驗完不將底稿送到網站。

**讀數口徑**：原表包含已獲發牌或註冊但尚未運作的機構；唔係零售分行、櫃員機或按母公司合併後的銀行集團。
本港代表辦事處不能經營銀行業務，亦不屬本頁三類認可機構。[現行制度](https://www.hkma.gov.hk/chi/key-functions/banking/banking-regulatory-and-supervisory-regime/the-three-tier-banking-system/)按原表及金管局說明為準。

每次更新一併檢查 `series`、`totals`、`source_components`、`updated_at`、`transcribed_at`、`period_notes`、
`source_note_zh` 和維護筆記嘅期數。未抄欄用 `null`，該類有任何一個來源欄缺值，分類值也必須 `null`，唔借舊月或填零。
只抄一個月時用期末長條，唔由單一月份聲稱歷史升跌。

**專用檢查**：三類及原表次序釘死；每類必須精確等於同牌照本地加境外兩欄；所有值只准非負整數或 `null`。
三類填齊便必須等於原表 `all_ais`，門檻為 **零間誤差**，唔沿用公共開支嘅一百萬元門檻。
總數不能混入代表辦事處，月份不能寫成 `YYYY-00`，截至日期必須是真正月末。
資料及正式源碼突變見 `scripts/test-banking-manual.mjs`。底稿本身抄錯或同時交換兩套值仍需逐格對原表；檢查不代替來源核對。

**授權**：[金管局《使用條款及條件》](https://www.hkma.gov.hk/chi/other-information/terms-and-conditions-of-use/)
第 12 段容許符合條件的非商業展示／複製，須準確並識別金管局為來源及知識產權擁有人。
本檔採官方原始數目，只按牌照將兩個註冊地欄位相加，明示處理及教育用途；保留原表與條款入口。

## 抄完之後

```bash
npm run validate     # 驗 schema、PDF 次序、跨來源錨定、總額及口徑閘
npm run test:checks  # 檢查器突變自證(零網絡)
npm run build        # 首頁張卡會自動出現
npm run test:offline # 離線行為，要真係通過，唔可以 SKIP 當成功
git add manual/ src/data/_snapshots/
git commit -m "人手更新:<邊個指標> <期數>"
```

## 年度節奏(建議)

| 月份 | 做乜 |
|---|---|
| 課堂使用前 | 核對 `banking_institutions` 最新月末原表，按需要人手更新 |
| 3 月 | 預算案出咗:抄 `public_expenditure_policy_groups`(3 個年度)|
| 每季(1、4、7、10 月)| 房屋局出咗新一季:抄 `phr_waiting_time` 一個期數 |

大部分指標一年更新一次就夠。唔好追每月數 —— 追唔切反而令個站長期顯示「數據截至」好耐之前。

## 澳門：四項 2025 年度概況

按擁有人要求新增澳門城市觀察，沿用每個指標一份 manual 的流程，唔新增自動排程。
目前四項只收錄 2025 年；每學年備課前一併核對上一完整年度正式刊物及修訂，
未抄下一年之前，頁面繼續明示 2025 固定快照，唔改成「最新」。

| 檔案 | DSEC 原刊第 1 頁欄位 | 2025 原數及單位 | 發布日 |
|---|---|---|---|
| `macau_population.json` | 《人口統計》2025 第四季，總人口（期末）本季 | 688,900 人 | 2026-03-16 |
| `macau_visitors.json` | 《旅遊統計》2025 全年，入境旅客總數 | 40,069,360 人次 | 刊物標示 2026.02；數字首發 2026-01-23 |
| `macau_inflation.json` | 《消費物價指數》2025 十二月，全年綜合平均通脹 | 0.33% | 2026-01-23 |
| `macau_gdp.json` | 《本地生產總值》2025 第四季，全年當年價格總值 | 4,180.4 億澳門元，詳細結果修訂值 | 2026-02-13 |

原刊 URL 及刊登須指出來源的聲明在各檔 `source_url`／`licence_url`，已視覺核對第 1 頁。
`updated_at` 為資料截至日 2025-12-31；發布日另記 `source_note_zh`／`period_notes`；
`transcribed_at` 記實際核對日。唔用建置日期冒充新資料。

抄數時逐項核對：

1. 人口係期末總人口，唔抄本地人口或單一性別；旅客係全年人次，唔抄十二月、過夜旅客或獨立人數。
2. 通脹係全年平均，唔抄十二月按年率、甲類／乙類 CPI 或指數點數。
3. GDP 係全年當年價格總值，唔抄第四季、人均值、實質增長率或初步估算；單位保持澳門元。
4. GDP 原報 4,180.4 億轉成整數 418,040,000,000 澳門元，manual 用已核對整數、倍率 1。
   JavaScript 直接以 `4180.4 * 100000000` 會出現二進位浮點尾差；不要存這個尾差或擅自全域放寬門檻。
   原報精度只有 0.1 億，換算說明必須保留。其餘三項亦採原單位、倍率 1。
5. 更新來源、日期、定義、錨點算式與對應期數一起核對；如新增歷年資料，才修改專頁「只收錄 2025」及圖表。
6. 執行 validate、test:checks、build、test:offline，核對澳門四卡、資料表及引用。
   香港首頁「全港數據總覽」保持香港指標；澳門有獨立入口。全站離線橫額會計入澳門已填統計的截至日。

DSEC 提供 SOAP Web Service，但本輪選擇四份正式刊物的人手快照，避免為少量年度資料
增加 XML 轉接、發布日補齊及跨表維護；未把 PDF 解析器加入生產流程。
