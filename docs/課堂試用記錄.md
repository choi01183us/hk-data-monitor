# 小規模課堂試用記錄

呢份係本站建議嘅一次試用安排及空白記錄，**未有真人試用結果，唔係已驗證成效或計劃指定標準**。先邀請一位老師同一小組學生試行；人數、時長同分工按校情調整。老師備課包已有教材及課節示例，今次只查四項操作同推理有冇卡住，唔另教一套課程。

只用紙本或校方文件，由老師保管。記全組今次表現，唔記姓名、學號、個人家庭資料、錄音或可識別個人嘅影像；唔建立學生代號、排名或跨次追蹤。網站唔接收、儲存或提交答案。
