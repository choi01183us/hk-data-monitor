喺本機同 GitHub Pages 都唔同。

## A. 首次載入

- [ ] 首頁開得到,11 張指標卡全部出到
- [ ] 冇橫向捲軸(頁面唔可以左右拉)
- [ ] **實際字型** —— 中文有冇變成系統預設嘅難睇字體?
      (站內冇載任何外部字型,所以睇嘅係手機自己嘅中文字型)
- [ ] **瀏覽器工具列食走嘅高度** —— 首屏見唔見到第一張卡?
      定係要碌先見到?(iOS Safari 個網址列會食走頗多)

## B. 觸控

- [ ] **觸控目標大細** —— 指標卡、「資料表」摺疊掣、來源連結,
      撳得中定要對準?(WCAG 建議至少 44×44 CSS px)
- [ ] 資料表打開之後,表格橫向捲得順唔順?會唔會同頁面上下捲打架?
- [ ] 側欄(漢堡選單)開得到、揀得到、閂得返

## C. 圖表(390px 之下)

- [ ] **軸標籤有冇疊埋一齊?** 尤其係財政年度嗰批(`2000–01`、`2005–06`…)
- [ ] **10px 嘅刻度數字睇唔睇得清?**
      (對比度量過:淺色 16.71:1、深色 12.43:1,唔係對比度問題,係字細)
- [ ] 六條線嘅政府收入圖,圖例分唔分得開?
- [ ] 撳圖表出唔出到 tooltip?手指撳(唔係滑鼠 hover)有冇反應?

## D. 錨點算式

- [ ] **算式一行過定斷行?** 例如
      「點計出嚟:7,652 億 元 ÷ 2026 年 6 月人口 752 萬 人」
- [ ] 斷行之後仲讀唔讀得明?數字有冇被斬開?

## E. 離線(飛行模式)

先喺有網嘅情況下開一次首頁,**等 5 秒**(service worker 要抓埋圖表 library),
然後開飛行模式:

- [ ] 重新載入首頁 —— 出唔出到?
- [ ] 頁頂有冇「目前為離線快取,數據截至 YYYY 年 M 月 D 日」橫額?
- [ ] **由首頁撳入一版之前未載過嘅指標** —— 出唔出到?圖畫唔畫到?
- [ ] 開一個唔存在嘅網址(例如 `/indicators/xyz`)—— 應該出 404 版,
      **唔應該出首頁內容**
- [ ] 關返飛行模式,重新載入 —— 橫額有冇收返?

- [ ] 「加到主畫面」有冇出到自訂圖示同名(「香港數據」)?
