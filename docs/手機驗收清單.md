每次改完 UI，喺真手機或平板按受影響項目覆驗；首次部署要完整行一次。Playwright 嘅手機 viewport 唔等於真裝置。**呢份係待填清單，唔代表已通過驗收。**

## A. 首次載入與版面

- [ ] 首頁及導覽開得到，地圖、新聞、天氣同已發布且有數據嘅指標卡有內容，冇錯誤訊息或空白區塊。按本次發布內容核對，唔用固定卡數判斷。
- [ ] 直向及橫向冇整頁橫向捲軸；資料表本身可以橫向捲動。
- [ ] 中文字型、數字同來源文字清楚；深色／淺色模式都可讀。
- [ ] 瀏覽器網址列展開／收起時，首屏標題、地圖入口同導覽可見可按，冇控制被工具列遮住。
- [ ] 網頁可雙指放大，文字唔被截斷；放大後仍能操作導覽及返到原位置。

## B. 觸控與地圖

- [ ] 指標卡、資料表摺疊掣、來源連結、選單及關閉掣容易按中，唔會誤觸旁邊控制。
- [ ] 側欄開得到、揀得到、閂得返；表格橫向捲動同頁面上下捲動唔打架。
- [ ] 到 `explore/city#city-map`，用地圖放大／縮小、方向掣、香港全景同定位所選；地區、標記同底圖保持對齊。
- [ ] 放大後單指拖移，放手唔會意外選中另一地點；雙指係縮放網頁，唔要求地圖增加底圖細節。
- [ ] 選區、換年份、搜尋景點後，資料同所選項目吻合，地圖視野唔無故跳走。地圖以外仍可正常捲動頁面。
- [ ] 如裝置提供全螢幕，試進入、退出及轉向；唔支援時記「裝置不支援」，並確認原位縮放／移動仍可用。

## C. 圖表、口徑及引用

- [ ] 軸標籤、財政年度、刻度、圖例同資料表清楚，冇疊字或截字。用手指點圖表核對提示；若某圖無觸控提示，原數仍可喺資料表讀到。
- [ ] 公共經常開支頁切換年度／增減後，圖表同引用一齊轉；註腳仍清楚分開經常開支同開支總額。
- [ ] 公屋輪候頁嘅三類指標、統計期、定義同來源可完整閱讀，唔將三類數字相加或當成某個申請者預計等候時間。
- [ ] 錨點算式換行後仍讀得明，數字、單位、人口分母年份唔會被遮住。
- [ ] 揀一項數據，複製引用到本機空白文件，核對來源、時期、數值、單位同口徑。若剪貼簿不支援，試手動選取引用文字；測完刪除測試文件。
- [ ] 連線時官方來源外鏈可開，返到網站仍可繼續；外部網站唔屬本站離線快取。

## D. 英式英文

- [ ] 首頁、城市地圖、兩個上述指標頁、老師備課及小測頁切換 `en-GB`；介面冇漏譯、截字或變成錯誤數字。來源刻意保留嘅官方中文原文有語言提示。
- [ ] 切換語言保留當前頁及錨點；站內下一條連結沿用語言，官方外鏈及下載網址冇被加上語言參數。
- [ ] 英文引用嘅年份、數值及口徑同中文一致；切返中文後亦正常。

## E. 離線：首次未訪頁及飛行模式

用一個可清除本站資料嘅測試瀏覽環境開始，先記低哪些指標／教學頁**未曾打開**。有網時只開首頁，保持頁面開啟讓快取完成。**唔用「等五秒」當完成證據。** 維護者有遠端除錯工具時可確認本站 service worker 已啟用並控制頁面；仍須做以下斷網實測，因為單有 active 狀態唔保證每個圖表資源都成功快取。

- [ ] 開飛行模式，另確認 Wi-Fi 同流動數據都已關閉；唔只睇網站嘅在線狀態。重新載入首頁，內容應可讀。
- [ ] 頁頂出「目前為離線快取」提示及資料日期說明；唔將全站最早截至日期誤當所有資料嘅統計期。
- [ ] 由首頁進入**本輪之前未訪過**嘅指標頁，圖表、資料表、引用都可用。記下路徑：＿＿。
- [ ] 仍然斷網，首次開城市頁同老師備課頁，試地圖操作、站內連結及語言切換。記下之前有冇訪過：＿＿。
- [ ] 新聞／航班／天氣保留自身日期及快照說明；離線唔會變成即時資料，官方外鏈唔冒充已快取。
- [ ] 開一條本站不存在嘅路徑（如 `indicators/xyz`），應顯示搵唔到頁面，唔應以首頁冒充。
- [ ] 關閉頁籤後仍然斷網，重新輸入正式網址；再確認可讀。若失敗，記錄係首次快取未完成、儲存被清除，定重開行為有別，唔自行填通過。
- [ ] 恢復網絡並重新載入，離線提示應收起；確認頁面係今次發布版本，唔以舊快取當新部署成功。
