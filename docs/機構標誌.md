# 金融機構名稱與標誌

2026-09-09 按擁有人要求，研究港交所等四個機構的標誌點樣加入現有金融導讀。
四個機構沿用 `hong-kong-industries.js` 的職能卡：香港金融管理局（HKMA）、
證券及期貨事務監察委員會（SFC）、保險業監管局（IA）及香港交易所（HKEX）。

SPEC 第 2 節原本要求來源機構、來源連結及截至日期，冇把來源標誌列為必需，
亦唔會因為可用公開數據而授予品牌圖像的重用權。
今次係擁有人已批准的金融導讀及介面延伸，沿用單人維護、純靜態及離線優先原則。
本輪完成文字機構卡及官方入口；未下載、重製、修改或加入四間機構的官方 logo。

## 現階段的文字機構卡

`financial-institutions.js` 由既有 `industryRegulators` 及 `industrySources` 讀取名稱、
職能和官方連結，唔另建一份會逐漸不一致的機構資料。
縮寫以本站字體顯示，配中文名稱及職能；唔重畫官方圖形、描摹官方字形或模仿品牌排版。
呢啲係普通文字識別，唔應叫做「官方 logo」。

卡片保留「本站編寫嘅機構導讀；各機構並無贊助或認可本站」的說明。
港交所係市場營運集團，旗下聯交所的上市前線監管職責另行說明，
唔將佢呈現成與金管局、證監會、保監局完全相同的機構。

SFC 入口旁提供[證監會免責聲明](https://www.sfc.hk/TC/Quick-links/Others/Disclaimer)；
IA 入口旁提供[保監局主站法律資料（英文）](https://www.ia.org.hk/en/legal_information.html)。
提示保留在連結附近，唔藏在全站頁尾。
外部網站以普通連結另開，唔使用 iframe，也唔把官網頁面包成本站的一部分。

卡片只需本地 HTML／CSS，唔新增圖像 CDN、第三方字體、追蹤、資料抓取或儲存。
完成網站快取後，機構導讀仍可離線閱讀；前往官方網站則需要連線。

## 日後加入真正官方標誌的條件

若有適用授權，先確認該授權覆蓋本網站的具體用途，然後先加入原檔：

1. **權利依據**：SFC、IA、HKEX 需取得足以涵蓋本用途的權利人書面許可或另有明確適用授權。
   HKMA 可先評估上述非商業原樣重用條件是否完全適用；超出條件或可能暗示關聯時，按其規定取得書面同意。
   本文件只記錄來源條款，唔當作機構已向本站授權。
2. **公開及離線用途**：許可須涵蓋實際網站網域、公開教育展示、本地檔案存放和 PWA／service worker
   對使用者裝置的離線快取。如會放入公開 repo，亦要確認可隨原始碼再分發該資產。
   如果只准連線展示、禁止離線存檔或公開資產分發，就繼續用文字卡。
3. **原檔與版式**：只用權利人官方提供或書面指定的 SVG／PNG 等檔案；保留來源網址、取得日期、
   版本及授權證據。依官方留白、尺寸、顏色和背景規定展示，唔改色、裁走名稱、拉伸、加光暈或動畫。
   唔用截圖、第三方素材站或生成圖片代替官方原檔。
4. **辨識與維護**：保留可讀的中文名稱與角色，唔只靠圖形；鄰近文字已有完整名稱時，圖像可用空替代文字避免重複朗讀。
   記錄許可有效期、撤回及檔案更新條件，唔新增定時抓 logo 工作。
   如須撤下，移除資產引用、重建快取版本並核對發布清單；無法承諾即時刪除仍完全離線的裝置內容，授權範圍須容許此更新模式。

任何向機構查詢或申請的對外訊息，仍須擁有人明確授權後先可傳送。本輪並無對外聯絡。
