# 城市觀察：外國參考與香港功能

研究日期：**2026-09-09**。用途是為中學生的城市數據離線網站選擇值得參考的功能，
不是複製外站介面、品牌、截圖或整套程式。

## 四個官方參考

下表把來源已描述的功能與本站已實作的香港功能分開；借鏡方式屬設計判斷，
不代表外站採用同一技術，亦唔表示本站複製了外站所有功能。

| 官方參考 | 已核對的功能 | 現已落地於香港頁的做法 |
|---|---|---|
| [London Area Profiles](https://data.london.gov.uk/london-area-profiles) | 官方介紹列出地圖、圖表、表格，Borough／Ward 切換，以及選區後產生人口、經濟、社會、環境概況報告。 | 選十八區後顯示地區概況、人口及住戶入息、已收錄景點、來源和預算問題；「列印區情簡報」沿用瀏覽器列印。 |
| [新加坡 OneMap Population Dashboard](https://popquery.onemap.gov.sg/) | 站內導覽列出年份控制、所選區及全國數值、設施主題圖層、分布柱狀圖，以及有資料時提供的趨勢線。 | 共同年度選擇、所選區與全港參考並排，顯示佔同表全港人口比例及分母；十個代表景點支援類別與文字搜尋，地圖標記與清單同步。 |
| [NYC Population FactFinder](https://popfactfinder.planning.nyc.gov/) | [官方維護者程式庫](https://github.com/NYCPlanning/labs-factfinder)確認可選人口普查區、街區及社區組成研究範圍，再查看圖表和表格；[官方 API 說明](https://github.com/NYCPlanning/labs-factfinder-api)記錄當期、前期、變化及比較地區資料。 | 所選香港地區可對照另一區或全港，再選變化基期；人口與入息各有獨立歷史圖、原始表、差額、百分比及來源引用。 |
| [Dublin Economic Monitor](https://www.dublineconomy.ie/resources/) | 現行資源頁按主題列季度經濟圖表，包括就業、樓價、租金、交通及旅客；部分圖表比較 Dublin 與全國，並有簡報、資訊圖和歷期資源。 | 香港城市頁加入貿易與航運、住屋與物價、就業與收入、金融市場、科技與連繫五個主題，重用現有指標卡及快照，配定義、閱讀入口和公共需要問題。 |

所有按鈕、匯出及資料更新流程的瀏覽器互動驗收，不能寫成「已逐項實測全部功能」。
表內的外國統計網站是功能參考，不是本站統計數字的資料來源。

## 香港功能的資料邊界

地區概況只用人口及住戶入息兩表的共同年度。人口比例以同表、同年度全港
陸上非住院人口作分母，唔係人口密度或政府分區開支。全港住戶入息中位數直接取官方值，
唔把十八區中位數平均；所顯示的入息變化係名義變化，未扣通脹。

基期可以揀所選年度或之前已收錄的共同年度，差額及百分比均從兩期原值計算。
缺值唔補零、零基期唔計百分比；缺年及缺值令歷史圖斷線，唔插值。
人口與入息分成兩幅圖，每幅圖的兩條地區線共用同一個零起點刻度。
列印會展開概況內的歷史及引用，保留原表、來源、時期與計算說明；唔新增報告伺服器或答案儲存。

十個景點係課堂選錄，唔係設施普查或人氣排名。搜尋／類別篩選使用同一份結果畫標記和清單；
找不到相符地點唔等於該區冇設施。五個城市主題都係全港背景，唔把卡片數字套到選中地區，
亦唔將不同單位或時期的指標相加。金融機構以文字名稱識別，標誌條款另見[機構標誌](./機構標誌.md)。

## 澳門首版已完成，本輪隱藏

澳門首版曾完成獨立城市頁、六個地點的本地定位圖，以及人口、旅客、通脹與 GDP
四項 2025 年度快照，沿用地圖縮放、平移及全螢幕元件，並附港澳口徑提醒。
擁有人本輪要求隱藏澳門，現時公開網站聚焦香港，唔再顯示香港／澳門切換。

澳門主頁及四個指標 Markdown 設為 `draft: true`，首頁、導航及公開來源頁的澳門入口移除；
程式、地圖、manual、快照及來源紀錄全部保留，方便日後恢復。
Framework 按草稿狀態排除頁面；搜尋與離線快取依真正建置輸出產生。
離線資料截至日亦先按 dist 中已發布的指標附件篩選，唔讓留在 repo 的隱藏快照影響公開日期。

保留的澳門定位圖採用 [OpenStreetMap 澳門範圍](https://www.openstreetmap.org/relation/1867188)
及海岸線資料（2026-09-09 取得），離線製成簡化圖形。保留 **© OpenStreetMap contributors**
及 [ODbL 授權入口](https://www.openstreetmap.org/copyright)。它不是澳門官方界線圖；
只呈現主要陸地，不包含橫琴的澳門大學及口岸獨立管轄地塊。完整來源及製作範圍見
[澳門地圖資料檔](../src/data/macau-geography.json)的 `source`、`derivation` 及 `verification`。

## 日後恢復跨城閱讀時的比較條件

- **貨幣**：港元和澳門元分開標明。若日後需要換算，必須另列匯率來源、日期及換算方法；
  未換算的金額不做共同排名。
- **期間**：全年、季度、月度及期末數不能混在一起。來源更新日不等於數字所描述的統計期。
- **定義**：總人口、居民人口、就業人口及旅客人次不是同一分母；住戶入息和就業收入也不是
  同一概念。口徑未一致時，可並排閱讀，但不計差額、倍數或高低排名。
