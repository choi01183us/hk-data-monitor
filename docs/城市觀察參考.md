# 城市觀察：外國參考及澳門最小擴充

研究日期：**2026-09-09**。用途是為中學生的香港／澳門離線網站選擇值得參考的功能，
不是複製外站介面、品牌、截圖或整套程式。

## 四個官方參考

下表把來源已描述的功能與本站建議分開；「可借鏡」屬設計判斷，不代表外站採用同一技術。

| 官方參考 | 已核對的功能 | 本站可借鏡的低維護做法 |
|---|---|---|
| [London Area Profiles](https://data.london.gov.uk/london-area-profiles) | 官方介紹列出地圖、圖表、表格，Borough／Ward 切換，以及選區後產生人口、經濟、社會、環境概況報告。 | 點地區顯示固定格式的觀察卡：人口、用途、地標、來源及課堂問題；需要匯出時先用瀏覽器列印。 |

所有按鈕、匯出及資料更新流程的瀏覽器互動驗收，不能寫成「已逐項實測全部功能」。
表內的外國統計網站是功能參考，不是本站香港／澳門數字的資料來源。

## 澳門最小城市頁

現有香港頁已有地圖圖層、縮放、平移及全螢幕。新增澳門時，優先沿用這些元件，
把內容做成另一個清楚可選的城市，而非重新加入相同的地圖操作功能。

1. 在城市觀察導覽加入「香港／澳門」切換，讓每頁標題及資料範圍明確。
2. 澳門頁先放城市定位圖、少量代表地點，以及四項已核實的官方統計快照。
   每卡保留數據期、單位、來源更新日和完整引用；未取得的分區數據不補估計值。
3. 加一段城市特點及兩條觀察問題，幫學生由地理位置讀到人口、旅遊和經濟的關係。
4. 比較功能先用固定卡片或簡單表格；資料和圖形隨網站建置一同保存，瀏覽器離線仍可閱讀。

不用為這一輪加入帳戶、即時資料服務、AI 解說、3D 地圖或大型地圖 SDK。
本輪澳門定位圖採用 [OpenStreetMap 澳門範圍](https://www.openstreetmap.org/relation/1867188)
及海岸線資料（2026-09-09 取得），離線製成簡化圖形。保留 **© OpenStreetMap contributors**
及 [ODbL 授權入口](https://www.openstreetmap.org/copyright)。它不是澳門官方界線圖；
只呈現主要陸地，不包含橫琴的澳門大學及口岸獨立管轄地塊。完整來源及製作範圍見
[澳門地圖資料檔](../src/data/macau-geography.json)的 `source`、`derivation` 及 `verification`。

## 跨城比較先看三件事

- **貨幣**：港元和澳門元分開標明。若日後需要換算，必須另列匯率來源、日期及換算方法；
  未換算的金額不做共同排名。
- **期間**：全年、季度、月度及期末數不能混在一起。來源更新日不等於數字所描述的統計期。
- **定義**：總人口、居民人口、就業人口及旅客人次不是同一分母；住戶入息和就業收入也不是
  同一概念。口徑未一致時，可並排閱讀，但不計差額、倍數或高低排名。
