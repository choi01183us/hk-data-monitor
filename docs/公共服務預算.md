# 公共服務與預算：來源及年度維護

2026-09-09 按擁有人要求加入社會福利、教育及醫療各項服務。SPEC 第 6 節未列此 CSV；
本次新增一個已批准的官方來源，沿用第 5／7／8 節的指標 schema、定期快照、錯誤分類及離線快取。
不修改 SPEC，不啟動 §12a，不增加套件、背景服務或瀏覽器外部 API。

## 資料與範圍

- [2026 預算案 CSV 索引](https://www.budget.gov.hk/2026/chi/estimates1.html)
- [財政撥款原始 CSV](https://www.budget.gov.hk/2026/chi/csv/fin_provision.csv)
- 指標：`service_programme_provision`，30 綱領、90 點。只接中文 UTF-8 CSV；英文名稱經官方英文 CSV 核對後編入顯示字典。
- 六個總目：37 衞生署、140 醫務衞生局、156 教育局、170 社會福利署、173 職學處、190 教資會。
- 三期：2024–25 實際、2025–26 修訂預算、2026–27 預算。2025–26 原來預算仍驗格式，但不作圖中修訂數字。
- 發布日 2026-02-25，擷取日另記 `fetched_at`；來源固定為 2026 預算版，不宣稱自動換入下一年度。
- CSV 原單位百萬元、精度一位小數；先用整數十分位合併同綱領的指定機構，再乘 100,000 成港元。
  原始表／引用用港元，探索圖／表以百萬港元保留一位小數。數值未扣除通脹。

這是**綱領財政撥款**，包括部分非經常及非經營開支，不等同政策組別的經常開支。
三個主題只是閱讀分類：例如社區發展、違法者服務、公務員醫療、局長辦公室各有自己的政策範圍。
前端不設主題／跨綱領總額，不把政府與公共開支合圖、相加，也不把子計劃再加到其上層綱領。

社署政府機構欄包括其他總目及非現金成本，資助／私營機構欄為扣除費用收入的淨撥款，
不能直接比較兩類機構成本。七綱領之和與社署本年度總目預算四捨五入相符，不能聲稱必定不同；
但不應當作實際現金開支或全港社福經常開支。

特殊教育綱領只涵蓋特殊學校，不代表主流學校全部 SEN 支援。學生資助綱領不等同所有資助及貸款本金，
後者部分另由貸款基金支付。教資會是獨立總目，不能當成教育局子項再加一次。
衞生署部分 2024–25 數字已隨醫療改革重編，醫院牙科服務亦有轉移；只用同一 2026 預算版比較。

## 每年要做

1. 開新年度 CSV 索引及六份 PDF，人工確認總目、綱領名稱／編號、機構拆分、期數／狀態、單位及註腳。
2. 更新 `src/components/service-programmes.js` 的期數、來源、分類、雙語說明及 PDF 頁碼；
   更新 `src/data/_lib/service-budget.js` 的標題與發布日期，以及 `service-budget-view.js` 的年度文案。不得只替換 URL 年份後假設分類相同。
3. 視覺核對 PDF「財政撥款分析」：2026 版中文 170 p18、156 p12、173 p4（在職家庭津貼）／p1（學生資助）、
   190 p1、140 p9、37 p12。把新一期已核實的金額編入 `scripts/test-service-budget.mjs` 獨立 PDF 已知答案。
4. 用既有 refresh／fixture 交易更新正式錄影及快照，確認新版本完整配對。新來源／上游格式改變為 UpstreamError；
   程式、schema、換算及最終對源錯誤必須 hard fail。原版快照不被清空或填零。
5. 跑 `npm run test:checks`、`npm run build`、`npm run test:offline`，核對中英桌面及手機的圖、表、引用與官方連結後提交。

在同一年度只重抓此指標，可用既有 loader，不刷新其它資料：

```bash
HKDM_REFRESH=1 HKDM_FIXTURES=record node src/data/service_programme_provision.json.js
```

新增服務需求目前只連官方資料，不加另一套人工抄數：社會保障個案、安老輪候，教育學生／教師與資助處理目標，
醫管局病床／服務量／成效及衞生署健康服務。外部入口要連線。
如日後要把需求數字接入圖表，先分清財政年／學年／曆年、個案／人數／人次、核准學額／實際學生及服務重組，
再設獨立的來源 pin、定義、快照及突變測試；不把未接入的數值視作零。

## 檢查能證明甚麼

- schema：格式；English guard：中英定義配對；不代表金額真確。
- source pin：指定六總目、30綱領的名稱／編號／機構與8個欄名完整，未知、遺失、重複及壞值失敗。
- 最終逐格 guard：獨立用原來源字串重算90點，捉換算、錯欄、錯期及綱領錯配，任何一港元差異都失敗。
- 固定 PDF 已知答案：90點獨立核對，補足「新錄影與新快照同時漂移」的漏洞；更改必須回原表重驗。
- 同一綱領兩機構的數值若被互換，總額不變。此總額指標不能辨認該種上游錯誤，不聲稱可以。
- 原有公共經常開支的人手總額、PDF次序及跨來源錨定檢查和絕對1百萬元門檻不變，人手骨架仍待擁有人填寫。

中英文 PDF 排版頁碼不同：中文入口使用已視覺核對的頁碼，英文入口開官方英文 PDF 並標綱領編號，
不套用中文頁碼。英文服務需要入口同樣不借用未核實的中文頁碼。
