# 香港地圖教學定位點

資產：`src/components/hong-kong-places.js`。核對日期：**2026-09-09**。

這九個地點用來把商業、對外交通及郊野課題連繫起來，是編輯挑選的教學例子。
它們不是「全港主要地區」的完整排名，不是法定商業地帶、十八區或郊野公園邊界。
地點的功能可以重疊；「商業與就業／機場與港口／郊野與保育」只是瀏覽分類。
不把新界等同郊區，也不把大嶼山從新界分拆成互斥行政分區。
定位點沒有客流、船位、航跡、即時熱度或分區統計含義。

## 位置來源與坐標

全部取自[地政總署香港 1:50 000 地形圖](https://portal.csdi.gov.hk/csdi-webpage/dataset/landsd_rcd_1637221775627_85634)
的 `PLACANNO` 地名標註圖層（`MapServer/5`）。這是原圖的**標籤錨點**，
不是村落、公園或建築物的幾何中心，亦不是可作導航的入口。
例如機場用「赤鱲角」島名錨點；西貢東及南大嶼分別用公園內的北潭凹及鳳凰山定位。
它們不是航班位置、公園入口、碼頭泊位或山峰測量點。

先讀取圖層元資料，確認 `name=PLACANNO`、`geometryType=esriGeometryPoint`、
`latestWkid=2326`、存在 `OBJECTID`、`TextString` 及 `TYPE`。查詢指定 `outSR=2326`。
回應必須沒有 `error` 及 `exceededTransferLimit`，每個選用 ID 必須恰好一筆，
再逐一核對文字及類型；不能只因搜尋字眼相近就選用。
例如搜尋「金鐘」會找到山峰「大金鐘」，不能用它作金鐘商業區；
九龍灣同時有 `BAY`（海灣）及 `DIS`（地區）標籤，這裏用後者。

## 坐標工具先自證

沿用現有 SVG `viewBox="0 0 900 560"`，不重新投影或手動移動定位點：

```text
x = (E − 832250) × 0.0112 + 450
y = (824000 − N) × 0.0112 + 280
```

**先執行四組已知答案並全過，再轉換官方資料**（Node.js `assert.deepEqual`）：

| 輸入 E、N | 預期 x、y | 驗甚麼 |
|---|---|---|
| 832250、824000 | 450、280 | 顯示範圍中央 |
| 797000、849000 | 55.2、0 | 左上角及北向上 |
| 867500、799000 | 844.8、560 | 右下角及比例 |
| 837250、824000 | 506、280 | 向東 5,000 米只令 x 增加 56 |

```js
const toMap = (e, n) => ({
  x: Number(((e - 832250) * 0.0112 + 450).toFixed(2)),
  y: Number(((824000 - n) * 0.0112 + 280).toFixed(2))
});
```

輸出保留兩位小數只為固定排版；不能解讀成實地定位精度。
實際 map 圖層需與原 SVG 等比例重疊；畫面可移動文字排版，但不能為避字而搬動地理錨點。

### 回歸檢查及突變自證

`scripts/fixtures/places/landsd-placanno-2026-09-09.json` 只抽取上述九筆原始回應的
`OBJECTID`、`TextString`、`TYPE` 及 `geometry`，不把本站分類或推算的 SVG 坐標寫入官方錄影。
因此 `scripts/test-hong-kong-places.mjs` 能獨立從官方 HK80 坐標核對正式模組。
錄影本身的內容雜湊亦釘死，避免修改 expected 掩蓋位置錯誤。

檢查直接 import 正式 `hong-kong-places.js`，逐點釘死原圖 ID、名稱、兩軸位置、
三種分類及官方來源。突變包括調換 XY、替換成另一個真實 ID、缺點、重複 ID、
缺來源、來源改到非官方主機、第四分類及遺失日期；
另修改正式模組的臨時副本，把中環移位、改成另一個合法類別或刪去來源，
再 import 並交給**同一檢查器**，三項都必須報指定錯誤。
不改正式地點檔、錄影或網站快照來執行突變。
