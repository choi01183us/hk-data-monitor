## 實際取得的圖層

使用同一資料集的 [ArcGIS MapServer](https://portal.csdi.gov.hk/server/rest/services/common/landsd_rcd_1637221775627_85634/MapServer)。
每次請求均指定 `outSR=2326`、`f=json`。`outSR=2326` 代表香港 1980 方格網，
坐標次序為東距、北距，單位米。這些請求只在製作資產時執行，**不在網站建置或瀏覽器執行**。

| 圖層 | 篩選 | 用途 |
|---|---|---|
| `7`：HYDRPOLY | `TYPE='SEF'` | 海面多邊形，扣除後形成陸地及島嶼 |
| `17`：BDRYLINE | `TYPE='SAR'` | 封閉香港特區範圍，剔除境外陸地 |
| `5`：PLACANNO | `TYPE in ('ISL','DIS','BAY')` | 核對香港島、九龍、大嶼山及維多利亞港的原圖標籤位置 |

取得海面的可重複請求例子：

```sh
curl --fail --location --get \
  'https://portal.csdi.gov.hk/server/rest/services/common/landsd_rcd_1637221775627_85634/MapServer/7/query' \
  --data-urlencode "where=TYPE='SEF'" \
  --data-urlencode 'outFields=TYPE,CLASS,GRAPHICID,PHYSICALSTATUS' \
  --data-urlencode 'outSR=2326' \
  --data-urlencode 'f=json' \
  --output sea.json
```

界線請求使用圖層 `17`、`where=1=1`、`outFields=*`，再精確篩出 `TYPE='SAR'`。
標籤請求使用圖層 `5`、上表篩選及 `outFields=*`。更新時先讀圖層元資料確認編號及類型，
不要假設上游永遠不變；若回應有 `error`、`exceededTransferLimit` 或缺圖層，停下，不補假輪廓。

當次原始回應 SHA-256（只供日後對照，不是持續更新的網站數據）：

## 轉成 SVG 的方法

製作時用 Python 3.12、Shapely 2.1.2；pyproj 3.8.0 只用來核對投影已知答案。
工具安裝在暫存目錄，**不是專案依賴**，不加入 `package.json`、建置步驟或網站輸出。
不使用 PDF 地圖描圖、AI 生圖、手畫海岸或遠端地圖磚。

1. `BDRYLINE` 的 `SAR` 線段以 0.01 米精度接合，`polygonize(unary_union(lines))`
   取得一個封閉香港範圍。不是用一條自行畫的直線截斷新界。
2. 每項 `HYDRPOLY/SEF` 的各條 ring 用 `symmetric_difference` 按奇偶填色規則還原，
   保留陸地及島嶼孔洞，再聯集全部海面。
3. `land = sar.difference(sea_union)`。檢查結果是有效多邊形；
   不另外抹走小島，不加入十八區界線，也不按顏色暗示地區數據。
4. `land.simplify(25, preserve_topology=True)`，在來源方格網中以 **25 米**容差作拓撲保留簡化。
   這是為首頁縮圖減少節點，不是宣稱地圖有 25 米測量精度。
5. 不改變投影；沿用香港 1980 方格網（EPSG:2326）。
   SVG `viewBox="0 0 900 560"`；顯示範圍為東距 `797000–867500`、北距 `799000–849000`。
   以相同的 x/y 比例 `s = 0.0112` 縮放，北向上，坐標只在輸出時保留兩位小數：

   ```text
   x = (E − 832250) × s + 450
   y = (824000 − N) × s + 280
   ```

6. 背景細線是每 **5,000 米**一條的真實香港 1980 方格網，無統計含義。
   新界字樣放在新界本土中央作地域標籤；其餘地名參照 `PLACANNO`，
   微調排字避免遮住狹窄海港。維港引線終點沿用原圖中文標籤坐標
   `(834886.5328, 816856.1116)`，不把引線當測量標記。

### 製作工具自證及覆核

在使用幾何計算前，先核對四個已知答案：2×2 方形面積為 4；
4×4 方形扣 2×2 中心孔後為 12；兩個重疊的 2×2 方形聯集為 6；
封閉單位方形線只產生一個多邊形。另核對簡化不改變完整方形。

投影核對四個已知答案：香港 1980 投影原點、地政總署公布的 HK80 樣本，
以及 Web Mercator 的 `(0°,0°)` 和 `(180°,0°)`。
前兩項出處：[地政總署大地測量基準說明](https://www.geodetic.gov.hk/common/data/pdf/explanatorynotes_c.pdf)。
SVG 縮放另核對中央及兩角，確認東西、南北沒有交換或拉伸。

已用瀏覽器實際渲染及目視覆核港島、九龍、新界、大嶼山、離島與維港相對位置。
此覆核不代表可作量地、導航、海事、地界或最新填海進度判斷。
