# 香港行業導讀

2026-09-09 按擁有人新增「介紹行業，特別金融保險」實作。頁面以中三至中四學生為主，連起行業功能、市民生活、工作例子、技能、資料判讀及青年預算備忘。五個教學主題為金融、保險、貿易物流、旅遊、專業服務；唔係五個互斥統計分類。

## 範圍與維護

- `src/components/hong-kong-industries.js`：純文字內容、官方來源及相關站內連結；exports `industryTopics`、`industrySources`（亦有 `sources` alias）、`industryRegulators`、`industryProductTypes`。
- `src/components/industry-explorer.js`：`industryExplorer()`，無資料參數；沿用既有 htl，native radio 切換主題、`details` 打開課堂提示。無網絡請求、行情計算、帳戶或偏好儲存。
- `src/explore/industries.md`：獨立行業頁，沿用 monitor-home 版面。CSS、導航及全站驗證由現有主程式統一處理。
- 教學導讀可隨網站快取離線使用；官方資料以外部連結開啟，需連線。唔加新 npm dependency、API、數據 loader 或定時維護工作。
- 工作及技能係概括例子，唔係招聘資料、薪酬統計、入職保證或個人產品建議。課堂情境及公共支援提問由本站編寫，並非引用真實個案或已批政策。

## 金融與保險的邊界

1. 金融主題介紹銀行、支付、信貸、證券、IPO 與二手市場買賣；保險主題另外展開風險分攤、保費、核保、理賠、精算、再保險。唔把金融等同股市，亦唔把保險工作等同銷售。
2. 兩個主題各有 HKMA、SFC、IA、HKEX 職能卡。HKEX 係市場營運機構，旗下聯交所亦有上市前線監管職能；唔把佢當作同三個法定監管機構完全一樣。銀行證券業務的證監會註冊與金管局日常前線監管，按證監會原頁補充。
3. 存款、證券投資、保險分開說明；存保會原頁確認股票、基金及保險產品唔屬存款保障。唔抄存保上限、產品費率等需定期更新數字。
4. 保費唔等於保額、保險公司利潤、增加價值或政府開支；索償按事故、文件及條款，唔因有收據而假設全額賠償。公帑討論聚焦資訊、能力及服務需要，唔以保單銷售量代表政策成效。
5. 連去既有 `four_key_industries` 指標，唔複製舊數或估保險獨立比重。統計處 2025 年 12 月專題文章 §3.2 確認金融包括保險；§3.4 的「保險及其他金融服務」亦涵蓋多種金融活動，仍非保險獨立分類。
6. 同一文章 §4.2–4.3 確認旅遊包括入境及外訪旅遊。頁面情境聚焦訪港旅客，但明文分清教學例子與完整統計範圍。貿易物流頁連既有港口貨物吞吐量：公噸係貨物重量，唔係貨櫃 TEU；抵港及離港轉運貨物會各自計入。

## 引用、數字及後續改動

全文為本站簡短導讀與教學情境，來源頁只作連結及事實核對；無複製照片、標誌、整篇文章、行情表格或報告。唔把「官網可以打開」視為已取得第三方數據再發布權。HKEX 三個入口只提供閱讀連結，無新增表 34095003 loader；本改動亦無移除既有 hkex 指標。

日後更新集中喺 pure content 檔：確認連結、機構分工及涵蓋範圍，再更新核對日期。若需要新增薪酬、空缺、保險細分類或市場時間序列，須另做來源、授權、期間、單位及不變式核查；唔從現有大分類推算。

## 本地驗證記錄

兩個 JS 檔通過 `node --check`。以 repo 既有 htl + jsdom 做臨時 DOM 實跑：先確認文字 escaping、節點陣列插入、radio checked、details 開關四個已知答案，再逐一點選五主題，確認對應內容、金融／保險專用監管卡、原生提示開關、唯一 id 及站內目標存在。網絡函數設成一經呼叫就拋錯，整個切換過程無呼叫。

此處無新增數字量度工具或檢查器，亦無為純文案製造鏡像測試。整站 build、offline、版面及鍵盤驗證由本輪主整合一併執行；本記錄唔代替實際全站結果。
