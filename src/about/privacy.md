<h1 id="privacy">私隱</h1>

<p class="lede">一句話:呢個網站唔會收集你任何個人資料。</p>

<h2 id="not-collected">我哋冇做嘅嘢</h2>

- 冇 Google Analytics,冇任何分析或統計工具
- 冇 cookie,冇 tracking pixel,冇廣告
- 冇登入、冇註冊、冇個人資料收集表格
- 冇後端伺服器 — 成個網站係靜態檔案,冇資料庫
- 冇第三方字型或指令碼 CDN,所有資源同網站一齊寄存

<h2 id="data-flow">資料流向係單向嘅</h2>

```
公開 API ──(GitHub Actions,每星期一次)──▶ 靜態 JSON ──▶ 你嘅瀏覽器
```

抓數係喺 GitHub 嘅伺服器上、喺你打開網站**之前**就做好晒。
你嘅瀏覽器唔會直接去撩統計處或者任何政府 API,所以嗰啲機構亦都見唔到你嘅 IP。

<h2 id="verify">想自己驗證?</h2>

1. 開瀏覽器嘅開發者工具 → Network 分頁,重新載入,睇下有冇任何去第三方嘅請求(應該係零)
2. 睇 repo 入面所有程式碼 — 全部係純文字,冇打包過嘅黑箱
